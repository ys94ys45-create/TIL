# Claude + Playwright MCP로 네이버 블로그 자동화

## 한 일
Claude에 Playwright MCP를 연결해서 네이버 블로그 글쓰기를 자동화했다.

## 구현한 기능
- 사진 속 사람 얼굴 모자이크 처리
- 장소 태그 자동 추가
- 키워드(해시태그) 자동 입력
- 내 말투를 학습시켜 내 스타일대로 글 작성
- 이모티콘(스티커) 클릭해서 넣기

## 배운 점
- Playwright MCP를 쓰면 Claude가 브라우저를 직접 클릭하고 입력할 수 있다.
- 말투는 내가 쓴 글 예시를 주고 규칙으로 정리해 두면 잘 따라 한다.

1106 사진을주고 이미지를 읽어 글을 작성하는 것 외에
코엑스 전시 일정이랑 박람회일정 크롤링 후 작성하라고 한것도 잘 함
